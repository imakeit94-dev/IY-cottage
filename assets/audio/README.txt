音频文件放这里。网页按 motion.js 顶部 AUDIO_SRC 里的顺序尝试，第一个能载入的生效。

────────────────────────────────────────────────────────────────
背景音乐（循环播放，音量 20%）
  1. bgm.wav   ← 当前首选。16 秒无缝循环的占位垫音
  2. bgm.mp3   ← 后备，同时也是你放正式音乐的位置

  为什么 wav 排在 mp3 前面？
    用浏览器解码器逐样本量过：mp3 编码会在首部多出约 26ms 静音、尾部多出约 7ms，
    16 秒循环一次就出现约 33ms 的断口，连续垫音会听出轻微顿挫。
    wav 是无缝循环的，所以首选 wav、mp3 只作载入失败时的后备。

  换成正式音乐：
    1) 把文件命名成 bgm.mp3 放进本目录；
    2) 把 motion.js 里的
         bgm: ['assets/audio/bgm.wav', 'assets/audio/bgm.mp3']
       改成
         bgm: ['assets/audio/bgm.mp3']
    正式音乐通常首尾本身就自然衔接，重复循环时那点接缝基本听不出来。

────────────────────────────────────────────────────────────────
吉他音效（点小屋上的吉他时播放，音量 40%）
  guitar.mp3   ← 当前使用，约 2 秒的占位拨弦声
  · 一次性音效、不循环，所以不受上面 mp3 接缝问题的影响。

────────────────────────────────────────────────────────────────
调音量 / 换路径
  - 音量在 motion.js 顶部 AUDIO_LEVEL 里调（0–1，背景乐 .20 / 吉他 .40）。
  - 改文件名或换目录，同步改 motion.js 顶部的 AUDIO_SRC 即可。
